# Fonts

Static, Latin-only builds of the three families used on [abhayemekar.me](https://abhayemekar.me),
made by `scripts/build_fonts.py` from [google/fonts](https://github.com/google/fonts).
`scripts/render.py` subsets them again per SVG and embeds only the glyphs each image uses.
